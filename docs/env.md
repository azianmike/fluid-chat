# Environment Variables

```text
DATABASE_URL        Postgres connection string.
REDIS_URL           Redis connection string for realtime/pubsub.
SESSION_SECRET      Reserved for cookie signing extensions; use at least 32 chars.
APP_URL             Public app URL used for invite links.
SMTP_HOST           SMTP server host.
SMTP_PORT           SMTP server port.
SMTP_USER           SMTP username.
SMTP_PASSWORD       SMTP password.
SMTP_FROM           Email sender.
S3_ENDPOINT         S3-compatible endpoint.
S3_BUCKET           Object storage bucket.
S3_ACCESS_KEY       Object storage access key.
S3_SECRET_KEY       Object storage secret key.
STRIPE_SECRET_KEY   Reserved for hosted billing.
```
